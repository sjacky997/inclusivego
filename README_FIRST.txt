InclusiveGo 海濱樂園行程規劃｜組員測試版

這個 ZIP 只包含測試網站所需的頁面、三份 PDF 和本機啟動工具，沒有專案原始碼或其他私人文件。

開啟方法
1. 先將整個 ZIP 解壓縮。不要在 ZIP 預覽視窗內直接開啟網頁。
2. Mac：雙擊「START_MAC.command」。如系統阻止開啟，可在終端機進入這個資料夾，輸入 python3 serve.py。
3. Windows：雙擊「START_WINDOWS.bat」。如電腦沒有 Python，請先安裝 Python 3，或請組員把這份 ZIP 上傳到靜態網站服務。
4. 啟動後瀏覽器會開啟 http://127.0.0.1:隨機連接埠/ 。測試完畢，在啟動視窗按 Control-C 停止。

測試建議
- 完成問卷、查看景點和推薦路線。
- 測試「查看地圖路線」和「重播路線」是否捲動到地圖及播放紅線。
- 在「行前故事」按「建立我的個人化 PDF」，並在列印視窗選擇「儲存為 PDF」。
- 測試三個 PDF 下載按鈕。
- 若外部字型或小圖示未顯示，請確認電腦已連上網絡；主要地圖與感官圖片已包含在網頁檔案中。

注意
- 127.0.0.1 是你自己電腦上的測試網址，不能直接傳給其他人。請把 ZIP 傳給組員，讓每個人自行解壓及啟動。
- 這是供團隊測試的網站檔案，並非海洋公園官方網站；內容和設施資訊仍須以官方最新資料為準。
